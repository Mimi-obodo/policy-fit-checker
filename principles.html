The UI/UX principles this site is built on

Visibility of system status

The pipeline is never decorative: nodes show idle, working and done states that track real execution, and a live log reports what actually happened with the real catalog.

Honest language

No fake matches, no padded empty states, no invented data. When the catalog is thin, the site says so in plain words.

Progressive disclosure

Six questions, one at a time. The match runs only when enough is known to run it well.

Recognition over recall

Labels say "Senior" not "life stage category 07". The agents have names, faces and roles before they are expected to be trusted.

Consistency

One token system — ink, paper, platinum, slate — and one type pairing across every section, so restraint never has to carry branding.

Accessibility

Keyboard focus is visible everywhere, reduced-motion users get a stepped indicator instead of the pulse, and every interaction has a non-motion fallback.

Feedback and affordance

Buttons always do something, chips are obviously chips, and every agent node is a button you can actually press to meet the agent.

Responsive by default

Everything degrades gracefully to one column and a stacked pipeline on a phone, not a second design.
